# Crowd Datasets

To test the Crowd Movement Detection system, you can use publicly available crowd datasets.

## Recommended Datasets
1. **MOT16 / MOT20 (Multiple Object Tracking)**: High-density crowds in various lighting conditions.
2. **UCF CC 50**: Dense crowd images and videos for counting.
3. **PETS 2009**: Contains scenarios of crowd movement, dispersion, and evacuation.

## How to use test videos
1. Download video clips (e.g., MP4 format) from the datasets above.
2. Place them in the `videos/` folder or upload them directly via the dashboard UI.
3. The system will process them and generate metrics.

*Note: Do not commit large video files to the repository.*
